# Toffee Roller

Веб-панель для охоты за floating IP из белых подсетей Selectel: ключи, прокси,
подсети, пойманные IP, история и метрики. Telegram — только уведомления.

План работ по фазам — [PLAN.md](PLAN.md).

## Состав

- `backend/` — FastAPI + движок охоты (Python 3.12+), база SQLite.
- `web/` — Next.js 16 + Tailwind 4. Ходит в backend через `/api/*` своего же домена.
- `chrome-extension/` — локальное расширение Chrome для автозаполнения формы входа Selectel.
- `tools/rumap_to_whitelist.py` — сбор списка подсетей из среза rumap.

## Локальный запуск

```bash
cp .env.example .env   # и вписать APP_SECRET_KEY
```

Backend (порт 8200):

```bash
cd backend && python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m watchfiles --filter python --target-type function app.uvicorn_loop.serve_dev app
```

На Windows из корня проекта можно запустить `backend-dev.cmd`.

Web (порт 3200):

```bash
cd web && pnpm install && pnpm dev
```

На Windows из корня проекта можно запустить `frontend-dev.cmd`.

Панель: http://localhost:3200, Swagger: http://localhost:8200/api/docs

Или всё сразу в Docker:

```bash
docker compose up --build
```

## Браузерные тесты

Из корня репозитория установите Playwright и Chromium в окружение backend:

```powershell
backend/.venv/Scripts/python -m pip install playwright
backend/.venv/Scripts/python -m playwright install chromium
```

Запустите панель на `127.0.0.1:3200`, затем выполните:

```powershell
backend/.venv/Scripts/python -m unittest discover -s tools -p test_browser_automation.py -v
```

Тесты раздела «Ключи» проверяют импорт аккаунтов, открытие локальной вкладки
Selectel и подключение через IAM-токен. Запросы к Selectel и ответы подключения
IAM подставляются тестом.
Для проверки наблюдателя используется динамический виджет в Shadow DOM.

Для ручной проверки Cap.js откройте свою тестовую страницу в наблюдателе и
запустите CAPTCHA в окне Chromium. Подставьте адрес страницы в команду:

```powershell
backend/.venv/Scripts/python tools/browser_automation_test.py http://127.0.0.1:8000 --verify-timeout 60
```

Скрипт повторно подключает наблюдение при навигации и обновлении страницы.
Он сообщает о состоянии проверки и наличии токена. С `--verify-timeout`
скрипт завершится с кодом `0`, когда виджет сообщит об успешной проверке с токеном,
или с кодом `1` по тайм-ауту. Без этого параметра наблюдение продолжается до
закрытия страницы или `Ctrl+C`.

## Подключить аккаунт Selectel

1. В Toffee Roller откройте **Ключи → Подключить аккаунты**. Вставьте список или загрузите TXT. Подходят строки `123456` и `user@example.com | 123456`. Если загрузить TXT с паролями, панель отбросит их при разборе в браузере.
2. Выберите строку и нажмите **Открыть Selectel**. Вкладка откроется в вашем браузере, в том числе при размещении Roller на сервере Ubuntu. Введите данные вручную, через менеджер паролей или расширение ниже. Пройдите CAPTCHA, нажмите **Войти** и при необходимости подтвердите второй фактор.
3. В Selectel откройте **Профиль → Доступ → IAM-токен**, скопируйте токен с областью **Аккаунт** и вставьте его в Toffee Roller. Нажмите **Подключить аккаунт**. После успешной проверки ключ появится на паузе.
4. Перед входом в следующий аккаунт выйдите из текущего в Selectel. В Toffee Roller нажмите **Следующий аккаунт**.

Roller выбирает доступный прокси для своих запросов. Вкладка Selectel использует настройки сети вашего браузера. При пустом балансе пополните его в Selectel и нажмите **Проверить после оплаты** в Roller. [Инструкция Selectel](https://docs.selectel.ru/balance-and-payments/manage/top-up-balance/)

### Автозаполнение в Chrome

1. На своём компьютере откройте `chrome://extensions`, включите **Режим разработчика** и через **Загрузить распакованное расширение** выберите папку `chrome-extension` из репозитория.
2. Нажмите значок **Toffee Roller → Импорт и очистка списка**. Загрузите TXT в формате `user@example.com | пароль | 123456`. Расширение держит список в памяти браузера до его перезапуска. Его можно удалить кнопкой **Очистить список**.
3. Откройте Selectel из строки аккаунта в Roller. Во вкладке Selectel нажмите значок расширения, проверьте номер и нажмите **Подставить данные**. Если после перенаправления номер не подставился, выберите его в расширении. Дальнейшие шаги входа выполните во вкладке Selectel.

### Из терминала

1. Войдите в панель Selectel через прокси и подтвердите вход кодом. Откройте **Профиль → Доступ → IAM-токен** и скопируйте токен с областью **Аккаунт**. Используйте токен владельца или пользователя с правами на создание проектов, чтение баланса и управление сервисными пользователями. [Инструкция Selectel](https://docs.selectel.ru/account/manage-keys/)
2. Добавьте прокси в Toffee Roller. Его `id` можно посмотреть в ответе `/api/proxies` на адресе панели, пока вы вошли как администратор.
3. Запустите команду в интерактивном терминале. Замените `123456` номером аккаунта Selectel, а `1` идентификатором прокси.

   ```powershell
   cd backend
   .venv/Scripts/python -m app.cli onboard-account 123456 --proxy-id 1
   ```

   Для Docker Compose запустите из корня репозитория.

   ```bash
   docker compose exec backend python -m app.cli onboard-account 123456 --proxy-id 1
   ```

Команда запросит IAM-токен без отображения ввода. Она проверит баланс, найдёт или создаст проект `toffee-roller-<номер аккаунта>`, создаст сервисного пользователя с ролью `member` в этом проекте и сохранит его ключ на паузе. Пароль сервисного пользователя хранится в БД в зашифрованном виде. Для другого имени проекта укажите `--project-name "имя проекта"`.

Пополните пустой баланс в панели Selectel перед повторным запуском команды. Первое пополнение и минимальный баланс для назначения роли `member` составляют 200 ₽. [Пополнение баланса](https://docs.selectel.ru/balance-and-payments/manage/top-up-balance/), [роль `member`](https://docs.selectel.ru/access-control/users/manage-service-users/add-service-user/)


### Код входа по почте

Блок MailyGet позволяет отдельно получить код: сначала нажмите
«Ждать новый код», дождитесь начала ожидания, затем запросите код в Selectel.
Старые письма пропускаются; при закрытии окна или смене аккаунта ожидание отменяется.

Адреса MailyGet настроены по умолчанию. При необходимости переопределите в `.env`
`MAILYGET_LIST_URL` (обязательно `{email}`) и `MAILYGET_DETAIL_URL_TEMPLATE`
(обязательно `{id}`, также поддерживается `{email}`). Значения подставляются с URL-кодированием.
Если API требует авторизацию, задайте `MAILYGET_AUTHORIZATION` и/или `MAILYGET_COOKIE`
на сервере и перезапустите backend. Эти секреты не передаются в браузер.

### Ротация прокси

Режим ключа `auto` выбирает случайный доступный прокси при запуске и перед каждой
попыткой получения IP. Если доступны другие прокси, предыдущий исключается.
Одна попытка (выделение IP, проверка и удаление неподходящего адреса) завершается
на одном прокси. Для `password_suffix` при переключении меняется также ID сессии,
в том числе если в сохранённом пароле уже был `_session-...`.

При подключении по IAM-токену Roller выбирает прокси и использует одну сессию
для проверки аккаунта, создания проекта и сервисного пользователя.
Новые ключи сохраняются в режиме `auto`. Недоступные (`dead`) прокси исключены;
если доступных нет, операция останавливается без прямого подключения.
При единственном статическом прокси другой внешний IP обеспечить невозможно.
Ручные режимы `fixed` и `none` остаются явными исключениями в настройках ключа.
